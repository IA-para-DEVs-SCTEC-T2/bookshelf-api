# Desafios da prática CI/CD

## Desafio 1 — Gerar workflow

Use Kiro, GitHub Copilot, Cursor ou ChatGPT para criar:

.github/workflows/ci.yml

O workflow deve validar backend, frontend, documentação e executar uma etapa final de deploy.

## Desafio 2 — Completar OpenAPI

Atualize backend/openapi.yaml com todos os endpoints implementados em backend/src/app.js.

## Desafio 3 — Completar documentação

Crie ou complete:

- docs/ARCHITECTURE.md
- docs/INSTALLATION.md
- docs/diagrams/api-flow.md

## Desafio 4 — Adicionar testes

Complete os testes do backend e frontend usando os arquivos existentes como base.

## Desafio 5 — Abrir Pull Request

Crie uma branch, altere o título principal da aplicação e abra uma Pull Request.

## Desafio 6 — Analisar falha

Quando o pipeline falhar, copie o log e use IA para diagnosticar.

A análise deve conter:

- objetivo do experimento;
- o que foi alterado;
- por que falhou;
- correção aplicada.
